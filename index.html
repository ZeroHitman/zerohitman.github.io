3Tentang ZeroHitman

ZeroHitman adalah nama portofolio dan identitas riset di bidang keamanan siber. Fokus utama pada web application security, bug bounty, dan source code review — dengan pendekatan research-driven dan open-source.

Semua tools, artikel, dan riset di sini adalah hasil eksplorasi mandiri yang didokumentasikan secara terbuka. Tujuannya: membangun portofolio yang dapat diverifikasi, sekaligus berkontribusi ke komunitas keamanan siber.

Fokus Riset

Bidang yang menjadi fokus utama:

Web App Pentest SQL Injection Local File Inclusion Bug Bounty Source Code Review Laravel Security PHP Security Reconnaissance

Area of Interest

Topik yang sedang dieksplorasi secara aktif:

  • Web Application Penetration Testing
  • Bug Bounty Research
  • Source Code Review (PHP / Laravel)
  • Recon Automation & Tooling
  • Linux Privilege Escalation
  • Active Directory Attack Research

Prinsip Kerja

Etis. Semua eksperimen dilakukan di lab pribadi, platform latihan legal (HTB, THM, PortSwigger), atau program bug bounty dalam scope.

Terbuka. Semua tools dan riset dirilis open-source supaya bisa diverifikasi, dikritik, dan ditingkatkan bersama.

Sederhana. Tools dibuat untuk bisa dipakai — bukan untuk flexing. Fokus pada fungsi, bukan gaya.

Bertanggung jawab. Jika kamu menemukan celah dari konten di sini, gunakan jalur responsible disclosure.

Kolaborasi

ZeroHitman adalah proyek riset independen yang terbuka untuk kolaborasi teknis, diskusi keamanan, dan kontribusi open-source.

Terbuka untuk:

Research Collaboration Open Source Technical Discussion Bug Bounty Collab

Semua aktivitas mengikuti prinsip etika keamanan siber dan responsible disclosure.

4Pertanyaan Umum

Siapa ZeroHitman?

ZeroHitman adalah nama portofolio seorang security researcher dari Indonesia dengan fokus pada web application penetration testing, bug bounty hunting, dan source code review. Riset, tools, dan artikel dibagikan secara terbuka melalui GitHub dan situs pribadinya.

Apa fokus riset ZeroHitman?

Fokus utama riset adalah web application penetration testing (SQL injection, local file inclusion, authentication bypass), bug bounty research, source code review pada PHP dan Laravel, serta recon automation. Hasil riset didokumentasikan di GitHub dan di halaman tree.html.

Apa saja tools yang dikembangkan ZeroHitman?

Beberapa tools open-source: ZeroTools (toolkit riset), ZeroCeker (sorter web app untuk triage), ZeroLOLV2 (recon toolkit), dan beberapa proyek lain yang dapat dilihat di github.com/ZeroHitman.
